# B站多账号切换

B站网页端多账号切换小助手（浏览器插件，Manifest V3）。在 B站顶部用户菜单里加个“切换账号”按钮，方便在几个号之间来回切，不用每次都退出再登录。

当前是 `1.0.0-beta`。

## 主要功能

- **自动记录账号**：在 B站 登录后，插件会自己读取当前账号的昵称、头像和登录信息存下来，不用手动添加。
- **切换账号**：在 B站页面顶部的“退出登录”上方加个“切换账号”按钮，点一下旁边就弹出个面板。
- **没登录也能用**：未登录时入口挂在顶部“登录”旁边，照样能打开面板切到存过的号。
- **账号列表**：面板里展示已保存账号的头像和名称，当前正在用的号会标出来，点哪个就切到哪个。
- **添加账户**：点“添加账户”会弹出一个小登录窗口，登录成功后会自动记下这个号。
- **设置页**：插件有自己的完整设置页面，可以开关“切换后自动刷新”和“显示切换账号按钮”，也能在这里删除已保存的账号。

## 安装

1. 下载或克隆这个仓库到本地。
2. 打开扩展管理页：Chrome/Edge 是 `chrome://extensions`，Firefox 是 `about:debugging#/runtime/this-firefox`。
3. Chrome/Edge 打开“开发者模式”，点“加载已解压的扩展程序”，选这个文件夹；Firefox 点“临时载入附加组件”，选里面的 `manifest.json`。
4. 去 B站网页，登录几个号，然后就能在顶部菜单里用“切换账号”了。

> Chrome / Edge 需要 121 以上版本。Firefox 121 以上也能直接用，清单里同时写了两种后台脚本写法；要是 Firefox 里读不到登录状态，去扩展的站点权限里把 bilibili.com 打开。

## 文件说明

- 根目录：最新版本的插件文件，直接加载使用即可。
- `versions/`：历史版本归档，每个版本一个独立完整文件夹（如 `versions/v1.0.0/`、`versions/v1.0.0-beta/`），旧版本会被完整保留，不会被新版本覆盖。
- `manifest.json`：插件清单，Manifest V3。
- `background.js`：后台脚本，用 `chrome.cookies` 读写 B站 Cookie、自动抓当前登录信息、打开登录窗口。
- `content.js` / `content.css`：往 B站页面注入“切换账号”按钮和弹出面板。
- `options.html` / `options.css` / `options.js`：插件的设置页面。
- `icons/`：插件图标。
- `.gitignore`：本地 AGENTS.md 不会被上传。
