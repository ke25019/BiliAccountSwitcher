# B站多账号切换

简体中文 | [English](README.en.md)

B站网页端多账号切换小助手（浏览器插件，Manifest V3）。在 B站顶部用户菜单里加个“切换账号”按钮，方便在几个号之间来回切，不用每次都退出再登录。

当前是 `1.2.1`。

## 主要功能

- **自动记录账号**：在 B站 登录后，插件会自己读取当前账号的昵称、头像和登录信息存下来，不用手动添加。
- **精简账号数据**：每个账号只存 `SESSDATA`、`bili_jct`、`DedeUserID`、`DedeUserID__ckMd5`、`sid` 这几项登录相关 Cookie；主题、播放设置、buvid、分辨率这类通用项不按账号保存，导出配置也不会带。
- **切换账号**：在 B站页面顶部的“退出登录”上方加个“切换账号”入口，图标 + 文字 + 小箭头；鼠标移上去就弹出账号面板，移进面板不会关，移开自动收起。
- **切换更稳**：换号前先把当前号的登录状态更新保存；换号时跳过过期的短期票据，写入后用 B站 接口再确认一次，没登上就恢复原登录，不会把当前号搞成未登录。
- **没登录也能用**：未登录时入口放在顶部“登录”浮层里，照样能打开面板切到存过的号。
- **账号列表**：面板里展示已保存账号的头像和名称，当前正在用的号会打勾，点哪个就切到哪个。
- **完整设置入口**：账号面板底部有“完整设置”，点一下直接打开插件设置页。
- **添加账户**：在当前页面弹出登录窗（里面直接嵌 B站 登录页），不会新开标签页。会先保存当前账号再退出登录；登录新号后自动记下并刷新，取消关掉会自动切回原账号。
- **登录页本地账号**：B站 登录页“其他方式登录”右边多一个“本地账号”，未登录时可以直接用存过的 Cookie 登录。
- **深色模式**：入口、账号面板、登录弹窗和设置页都会跟随 B站 的深色模式，不用单独再开一份主题。
- **设置页**：账号管理、主题、自动刷新、调试日志、切换统计、配置导入导出；底部的“清除数据并删除所有 Cookie”会退出当前 B站 登录并清空插件数据。
- **调试日志**：B站页面按 F12 打开控制台，会看到 `[B站多账号切换]` 开头的日志；切换失败时会打印 Cookie 名单和切换步骤（只打印名字，不打印 Cookie 值）。

## 安装

1. 到 Microsoft Edge 加载项商店 点「获取」（目前尚未发布），浏览器会自动装好，以后也会自动更新。
2. 想手动装或是试测试版，请到 [Releases](https://github.com/ke25019/BiliAccountSwitcher/releases) 下载对应版本的 zip 解压，在扩展管理页打开「开发人员模式」→「加载解压缩的扩展」。

> Chrome / Edge 需要 121 以上版本。

## 文件说明

- 根目录：最新版本的插件文件，直接加载使用即可。
- `versions/`：历史版本归档，每个版本一个独立完整文件夹（如 `versions/v1.0.0/`、`versions/v1.2.1/`），旧版本会被完整保留，不会被新版本覆盖。
- `manifest.json`：插件清单，Manifest V3。
- `background.js`：后台脚本，用 `chrome.cookies` 读写 B站 Cookie、自动抓当前登录信息、退出当前账号。
- `content.js` / `content.css`：往 B站页面注入“切换账号”按钮和弹出面板。
- `login.js` / `login.css`：在 B站 登录页加“本地账号”登录方式。
- `options.html` / `options.css` / `options.js`：插件的设置页面。
- `icons/`：插件图标。
- `LICENSE`：PolyForm Noncommercial License 1.0.0。

## 调试

- B站页面按 F12，在控制台里搜 `[B站多账号切换]`，能看到账号同步、入口注入、切换步骤等信息。
- 切换结果会存一份，页面刷新后日志里还能看到“上次切换记录”，包括切换前后的 UID、结果和每一步。
- 后台日志：打开 `chrome://extensions`，找到这个插件，点“服务工作线程”旁边的“检查”，在它的控制台里也能看到同一前缀的日志。
- 日志里只输出 Cookie 的名字、域和路径，不会输出 Cookie 的值。
